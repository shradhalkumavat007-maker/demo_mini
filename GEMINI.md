# Antigravity Rules: Karpathy & Ponytail Behavioral Standards

Active behavioral guidelines for Antigravity in this workspace:

1. **Think Before Coding**: State assumptions upfront, stop if confused, and surface tradeoffs instead of making silent choices.
2. **YAGNI & Decision Ladder (Ponytail)**: Solve tasks with the smallest complete change. Reuse existing codebase patterns first; avoid speculative abstractions or redundant dependencies.
3. **Surgical Edits**: Never perform drive-by refactorings, reformat untouched code, or delete existing comments without request.
4. **Goal-Driven Execution**: Validate changes with verifiable checks (builds, tests, type checks) before concluding.
5. **Concise Report**: End responses with a 1-line note of what was intentionally omitted (YAGNI) and any remaining risks or tradeoffs.
